> 학교 학과체험 행사용 QR 유령 수집 모바일 웹게임의 이미지·인쇄물 에셋 발주서
> 이 문서의 각 PART를 통째로 복사해서 마누스에게 주면 된다.

| 항목 | 값 |
|---|---|
| 프로젝트 | 고스트 GO (Ghost GO) |
| 행사 | 학과체험 3일, 하루 약 100명, 총 300명+ |
| 장소 | 학교 건물 1~3층 실내 |
| 플랫폼 | 모바일 웹 (세로 9:16), 다크 테마 전용 |
| 톤 | Halloween × Cute Horror × School Mystery — 무섭기보다 귀엽고 신비롭게 |
| 필요 에셋 | 유령 20종 SVG · QR 카드 인쇄물 · 앱 아이콘 · 포스터 |

## 🔴 모든 에셋에 공통으로 적용되는 절대 조건

아래 5가지는 협상 불가다. 어기면 행사 당일 게임이 망가진다.

### 1. 저작권 — 기존 IP를 절대 연상시키지 말 것
포켓몬을 비롯한 기존 게임·애니메이션 캐릭터의 형태, 비율, 눈 모양, 색 조합, 이름 규칙을
따라하면 안 된다. 학교 공식 행사에 쓰이므로 100% 독창 디자인이어야 한다.

**구체적으로 피할 것**: 뾰족한 귀 + 둥근 몸통 조합, 볼에 원형 홍조 + 번개 무늬,
진화 단계를 암시하는 시리즈 구성, 몬스터볼류 포획 도구, 속성 상성 아이콘.

### 2. 유령 이미지는 반드시 SVG — PNG·JPG 금지
무료 호스팅 대역폭이 하루 한도가 있어서, PNG로 만들면 **행사 당일 오후에 사이트가 죽는다.**
실제 계산: PNG 사용 시 하루 전송량이 한도의 203%가 된다.

- 파일 형식: **SVG (벡터)**
- 파일당 용량: **8 KB 이하** (20종 합계 160 KB 이하)
- 래스터 이미지를 SVG 안에 `<image>`로 넣는 것도 금지 (용량이 같다)
- 필터·그라디언트는 최소한으로 (모바일 렌더링 비용)

### 3. 규격
```
viewBox="0 0 100 100"   (정사각 좌표계, 고정)
실제 표시 크기: 34px(도감 썸네일) ~ 200px(발견 연출)
```
**34px로 줄여도 무엇인지 알아볼 수 있어야 한다.** 가는 선과 작은 디테일은 사라진다.

### 4. 다크 배경 전용
배경색 `#0B0614` (거의 검정) 위에 올라간다. 어두운 색만 쓰면 안 보인다.
흰색 배경을 가정하고 그리지 말 것. 배경은 **투명**으로 저장한다.

### 5. 실루엣이 서로 확실히 달라야 한다
20종을 나란히 놓고 **검은 실루엣만 봤을 때** 서로 구분되어야 한다.
도감에서 미발견 유령을 검은 실루엣으로 보여주기 때문이다.

## PART 1 — 유령 20종 SVG (최우선)

### 공통 디자인 규칙

| 규칙 | 내용 |
|---|---|
| 하반신 | **모든 유령의 아래쪽은 안개처럼 흩어진다** (물결 모양 자락 3~4개). 20종을 하나의 시리즈로 묶는 장치 |
| 눈 | 단순한 검은 타원 2개 + 흰 하이라이트 점. 동공을 정교하게 그리지 말 것 |
| 표정 | 무표정~살짝 웃는 정도. 공포스러운 표정 금지 (초·중·고 학생 대상) |
| 팔다리 | 대부분 없음. 필요하면 안개로 흐려지는 형태로 |
| 윤곽선 | 없음 (면으로만 표현). 필요시 아주 얇게 |
| 몸통 | **사물의 형태를 그대로 유령으로 만든다** — 이 게임의 핵심 아이디어 |

### 파일명 규칙 (중요)

아래 표의 `shape` 값을 파일명으로 쓴다. 코드가 이 이름으로 찾는다.

```
public/ghosts/ribbon.svg
public/ghosts/box.svg
public/ghosts/board.svg
...
```

## PART 2 — QR 카드 인쇄물 (A4)

학생이 학교 벽에서 찾게 될 실물 카드다. **QR 인식률이 최우선**이고 디자인은 그 다음이다.

### 물리 규격 (인식률 확보 — 실측 근거 있음)

| 항목 | 값 | 이유 |
|---|---|---|
| QR 실제 크기 | **70 mm × 70 mm** | 30~50cm 거리에서 구형 안드로이드도 인식 |
| 오류정정 레벨 | **ECC H (30%)** | 낙서·훼손·반사에도 읽힘 |
| 여백(Quiet Zone) | QR 모듈 4개 분량, **최소 8 mm 완전 여백** | 이 안에 그림·글자가 들어가면 인식 실패 |
| 카드 크기 | A4 1장에 4장 (2×2) | |
| 용지 | **무광 100g 이상** | 유광은 복도 조명이 반사돼 인식 실패 |
| 색상 | QR은 **검정/흰색만** | 색깔 QR은 인식률이 급락 |

> ⚠️ **가장 흔한 실패**: 예쁘게 만들려고 QR 위에 유령 그림을 겹치거나 QR을 주황색으로 칠하는 것.
> 그러면 학생 절반이 스캔에 실패하고 행사가 무너진다. **QR 영역은 절대 건드리지 말 것.**

### 카드 레이아웃

```
┌───────────────────────────┐
│  🎃 고스트 GO             │  ← 상단 20mm: 로고 + 장식
│                           │
│   [유령 일러스트]          │  ← 유령 그림 (QR 위쪽에만)
│                           │
│  ┌─────────────────┐      │
│  │                 │      │
│  │    QR CODE      │      │  ← 70mm, 사방 8mm 완전 여백
│  │   (흑백 전용)    │      │
│  │                 │      │
│  └─────────────────┘      │
│                           │
│      SCAN ME              │
│   GG1-XXXXXXXXXX          │  ← 스태프용 코드, 10pt 이상
│                           │
│  ⚠️ 뛰지 마세요            │  ← 안전 문구 필수
└───────────────────────────┘
```

### 디자인 톤
- 배경: 어두운 보라~남색 그라디언트 (`#130A24` → `#1C1033`)
- 포인트: 네온 오렌지 `#FF7A00`, 보라 `#9D4EDD`
- 테두리에 옅은 안개/거미줄 장식 (QR 영역 침범 금지)
- **QR 주변 8mm는 반드시 단색 흰색**

### 유령 이름은 카드에 쓰지 말 것
스캔하기 전에 무엇이 나올지 모르는 게 이 게임의 재미다.
카드에는 유령 그림만 넣고 **이름은 넣지 않는다.** (그림도 실루엣으로 하면 더 좋다)

## PART 3 — 앱 아이콘 / PWA 아이콘

학생이 홈 화면에 추가했을 때 쓰인다.

| 파일 | 크기 | 형식 | 비고 |
|---|---|---|---|
| `icon-192.png` | 192×192 | PNG | 안드로이드 |
| `icon-512.png` | 512×512 | PNG | 스플래시 |
| `icon-maskable-512.png` | 512×512 | PNG | 안전영역 80% 안에 배치 |
| `apple-touch-icon.png` | 180×180 | PNG | iOS (투명 배경 불가) |
| `favicon.svg` | 정사각 | SVG | 브라우저 탭 |

디자인: 어두운 보라 배경 + 가운데 흰 유령 실루엣 + 네온 오렌지 테두리 글로우.
아주 작게 축소돼도 유령임을 알 수 있어야 한다. 글자는 넣지 말 것.

*(아이콘은 예외적으로 PNG를 쓴다 — 앱 설치 시 1회만 다운로드되므로 대역폭 부담이 없다)*

## PART 4 — 행사 안내 포스터 (A3 / A4)

학생이 행사장 입구에서 보고 참여하게 만드는 물건이다.

### 반드시 들어갈 내용
1. 제목 **「고스트 GO」**
2. 한 줄 설명: "학교에 숨어 있는 유령 20마리를 찾아라!"
3. **접속용 QR** (게임 주소로 연결 — 유령 QR과 명확히 구분되게 다른 색 테두리)
4. 참여 방법 3단계
   - ① QR로 접속해서 고스트 헌터 ID 만들기
   - ② 1~3층을 돌아다니며 벽에 붙은 유령 QR 찾기
   - ③ 스캔해서 도감을 채우고 오늘의 1등에 도전!
5. 안전 문구: "뛰지 마세요 / 계단에서 스마트폰 보지 않기 / 수업 방해 금지"
6. 개인정보 안내: "실명·학번·전화번호를 요구하지 않습니다"

### 톤
어두운 학교 복도 배경, 안개, 유령 몇 마리가 떠다니는 구도.
무섭게가 아니라 **모험이 시작되는 느낌**으로.

## PART 5 — 납품 전 검수 체크리스트

마누스에게 이 목록을 그대로 주고 **스스로 검사한 결과를 함께 제출**하게 할 것.

### 유령 SVG
- [ ] 20개 파일 전부 있는가 (파일명이 표의 `shape` 값과 정확히 일치)
- [ ] 각 파일 8 KB 이하인가
- [ ] `viewBox="0 0 100 100"` 인가
- [ ] 배경이 투명인가 (흰 사각형이 깔려 있지 않은가)
- [ ] `#0B0614` 배경 위에 올렸을 때 잘 보이는가
- [ ] 34px로 축소해도 형태가 구분되는가
- [ ] 20종을 검은 실루엣으로 만들었을 때 서로 구분되는가
- [ ] 하반신이 안개로 흩어지는 공통 규칙을 지켰는가
- [ ] 기존 게임 캐릭터를 연상시키지 않는가
- [ ] `<image>` 태그로 래스터를 넣지 않았는가

### QR 카드
- [ ] QR 크기 70 mm 이상인가
- [ ] QR 사방 8 mm가 완전한 흰 여백인가 (그림·글자 침범 없음)
- [ ] QR이 흑백인가
- [ ] 실제로 인쇄해서 30cm 거리에서 스캔해 봤는가
- [ ] 유령 이름이 카드에 노출되지 않았는가
- [ ] 안전 문구가 들어갔는가

## PART 6 — 받은 파일을 프로젝트에 넣는 방법

```
ghost-go/
└─ public/
   ├─ ghosts/          ← 유령 SVG 20개를 여기에
   │  ├─ ribbon.svg
   │  ├─ box.svg
   │  └─ ...
   └─ icons/           ← 앱 아이콘
      ├─ icon-192.png
      └─ ...
```

현재 코드에는 **임시 SVG 유령이 이미 들어 있어서 게임은 지금도 돌아간다.**
마누스 파일을 받으면 `src/components/GhostSprite.tsx` 한 파일만 교체하면 된다
(파일에서 SVG를 불러오는 방식으로 바꾸는 작업 — 30분이면 끝난다).

QR 카드는 인쇄 전에 **반드시 1장을 시험 인쇄해서 실제 폰으로 스캔 테스트**를 한 뒤
나머지를 뽑을 것. 20장을 다 뽑고 나서 인식이 안 되면 되돌릴 수 없다.
