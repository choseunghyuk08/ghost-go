# 「고스트 GO」 필수 에셋 제작 요청

학교 학과체험 행사용 **QR 유령 수집 모바일 웹게임**의 이미지 에셋을 만들어 주세요.
플레이어가 학교 1~3층을 돌아다니며 벽에 붙은 QR을 스캔해 유령 20종을 모으는 게임입니다.

톤: **Halloween × Cute Horror × School Mystery** — 무섭기보다 귀엽고 신비롭게.
초·중·고 학생이 학교 행사에서 즐기는 게임이라 공포스러우면 안 됩니다.

---

## 🔴 절대 조건 (어기면 사용 불가)

**1. 반드시 SVG. PNG·JPG 금지.**
  호스팅 대역폭 한도가 있어서 PNG로 만들면 행사 당일 사이트가 다운됩니다.
  실제 계산상 PNG 사용 시 하루 전송량이 한도의 **203%**가 됩니다.
  SVG 안에 비트맵을 `<image>`로 넣는 것도 금지입니다(용량이 같음).

**2. 규격**
```
viewBox="0 0 100 100"     ← 고정
파일당 8 KB 이하           ← 20개 합쳐서 160 KB 이하
배경 투명                  ← 흰 사각형 깔면 안 됨
표시 크기 34px ~ 200px     ← 34px로 줄여도 알아볼 수 있어야 함
```

**3. 어두운 배경 전용**
  배경색 `#0B0614`(거의 검정) 위에 올라갑니다. 어두운 색만 쓰면 안 보입니다.
  흰 배경을 가정하고 그리지 마세요.

**4. 저작권 — 기존 IP를 연상시키지 말 것**
  포켓몬 등 기존 게임/애니 캐릭터의 형태·비율·눈 모양·색 조합을 따라하면 안 됩니다.
  학교 공식 행사에 쓰이므로 100% 독창 디자인이어야 합니다.
  특히 피할 것: 뾰족한 귀+둥근 몸통, 볼의 원형 홍조+번개 무늬, 진화 단계 암시,
  포획용 구체 아이템, 속성 상성 아이콘.

**5. 20종의 실루엣이 서로 확실히 달라야 함**
  도감에서 미발견 유령을 **검은 실루엣**으로 보여줍니다.
  20개를 검은색으로 칠했을 때 서로 구분되지 않으면 실패입니다.

### 각 유령의 설정 (분위기 참고용)

**1. 복도령** — 아무도 없는 복도에서 실내화 끄는 소리만 남기고 지나간다. 사실 그냥 산책 중이라 마주쳐도 인사만 하면 된다.
**2. 사물함귀신** — 닫히지 않는 사물함 문 뒤에서 백 년째 살고 있다. 남의 물건에는 관심 없고 문 여닫는 소리만 좋아한다.
**3. 칠판귀신** — 지워진 글씨를 모아 자기 몸을 만들었다. 수업이 끝나면 칠판에 낙서를 남기고 도망간다.
**4. 급식실령** — 식판 위에 남은 김에서 태어났다. 잔반을 남기면 슬퍼하지만 화내지는 않는다.
**5. 정수기령** — 마지막 한 방울이 떨어질 때마다 조금씩 자란다. 물을 받아 가면 뒤에서 조용히 박수를 친다.
**6. 우산꽂이령** — 비 오는 날 잊고 간 우산들이 뭉쳐 만들어졌다. 맑은 날엔 할 일이 없어 현관을 서성인다.
**7. 화분령** — 창가 화분이 햇빛을 너무 오래 받아 정신이 들었다. 물 주는 사람만 기억한다.
**8. 게시판령** — 압정에 눌린 종이들이 답답해서 스스로 떨어져 나왔다. 새 공지가 붙으면 제일 먼저 읽는다.
**9. 계단귀신** — 계단 수를 세는 습관이 있어서, 한 칸이 더 있다고 우긴다. 뛰어 내려가는 학생을 제일 싫어한다.
**10. 과학실령** — 실험이 끝난 플라스크 안에 남은 빛으로 만들어졌다. 안전 수칙을 어기면 눈이 빨개진다.
**11. 음악실령** — 아무도 없는 음악실에서 한 음만 계속 누른다. 화음을 들려주면 기분이 좋아진다.
**12. 체육관령** — 마룻바닥에서 나는 끽 소리를 먹고 산다. 경기 날엔 관중석 제일 위에서 응원한다.
**13. 소화전령** — 한 번도 쓰인 적이 없어서 심심하다. 불이 나지 않기를 누구보다 바라는 유령.
**14. 분실물령** — 주인을 못 찾은 물건들의 마음이 모여 태어났다. 이름표만 보면 눈물을 글썽인다.
**15. 도서관령** — 아무도 빌려 가지 않은 책 속에서 나왔다. 조용히 해 달라는 뜻으로 책장을 딱 한 번 넘긴다.
**16. 거울귀신** — 거울에 비치지 않아서 늘 서운해한다. 자기를 봐 주는 사람에게만 모습을 보여 준다.
**17. 방송실령** — 점심시간 신청곡을 백 년째 기다리고 있다. 마이크가 켜지면 조용해진다.
**18. 석고상령** — 미술실 구석에서 백 년 동안 같은 각도로 서 있었다. 아무도 안 볼 때만 목을 돌린다.
**19. 시계귀신** — 복도 시계가 1분 늦게 가는 건 전부 이 유령 탓이다. 종례 시간만은 정확히 맞춰 준다.
**20. 제13교실령** — 있을 리 없는 교실 문 앞에서만 나타난다. 문을 열어 본 학생은 아직 아무도 없다.

## 추가 에셋 (유령 다음으로 필요)

### 앱 아이콘
```
icon-192.png            192×192   안드로이드
icon-512.png            512×512   스플래시
icon-maskable-512.png   512×512   안전영역 80% 안에 배치
apple-touch-icon.png    180×180   iOS (투명 배경 불가)
```
어두운 보라 배경 + 가운데 흰 유령 실루엣 + 네온 오렌지 글로우.
아주 작게 줄여도 유령임을 알 수 있어야 하고, 글자는 넣지 마세요.
*(아이콘만 예외로 PNG — 설치 시 1회만 받으므로 대역폭 부담 없음)*

### QR 카드 인쇄물 (A4)

학생이 학교 벽에서 찾을 실물 카드입니다. **QR 인식률이 디자인보다 우선입니다.**

| 항목 | 값 | 이유 |
|---|---|---|
| QR 크기 | **70 mm 이상** | 30~50cm 거리에서 구형 폰도 인식 |
| 오류정정 | **ECC H (30%)** | 낙서·훼손에도 읽힘 |
| 여백 | **사방 8 mm 완전 흰 여백** | 여기에 그림·글자가 들어가면 인식 실패 |
| QR 색 | **흑백만** | 컬러 QR은 인식률 급락 |
| 배치 | A4에 2×2 = 4장 | |

> ⚠️ **가장 흔한 실패**: 예쁘게 만들려고 QR 위에 유령 그림을 겹치거나 QR을 주황색으로
> 칠하는 것. 그러면 학생 절반이 스캔에 실패하고 행사가 무너집니다.
> **QR 영역과 그 주변 8mm는 절대 건드리지 마세요.**

레이아웃:
```
┌─────────────────────┐
│  🎃 고스트 GO        │
│   [유령 실루엣]      │  ← 이름은 쓰지 말 것
│  ┌───────────┐      │
│  │  QR CODE  │      │  ← 70mm, 사방 8mm 흰 여백
│  └───────────┘      │
│     SCAN ME         │
│  GG1-XXXXXXXXXX     │  ← 스태프용 코드
│  ⚠️ 뛰지 마세요      │
└─────────────────────┘
```
배경은 어두운 보라~남색 그라디언트(`#130A24`→`#1C1033`), 포인트는 `#FF7A00`.

**유령 이름은 카드에 쓰지 마세요.** 스캔 전에 뭐가 나올지 모르는 게 이 게임의 재미입니다.

## 납품 전 자가 점검

아래를 직접 확인하고 결과를 함께 알려주세요.

- [ ] SVG 20개, 파일명이 위 표와 정확히 일치
- [ ] 각 파일 8 KB 이하
- [ ] `viewBox="0 0 100 100"`
- [ ] 배경 투명 (흰 사각형 없음)
- [ ] `#0B0614` 배경 위에서 잘 보임
- [ ] 34px로 줄여도 형태 구분됨

**우선순위**: 유령 20종 SVG가 가장 급합니다. 아이콘과 QR 카드는 그다음입니다.
