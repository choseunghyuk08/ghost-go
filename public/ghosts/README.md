# 유령 이미지 넣는 곳

마누스가 만든 이미지 20개를 **이 폴더에 그대로 넣으면 끝**입니다. 코드 수정 불필요.

## 형식

`webp` (권장) / `png` / `svg` — 셋 다 됩니다. 코드가 이 순서로 찾습니다: **svg → webp → png**

| 항목 | 기준 |
|---|---|
| 배경 | **투명 필수** (어두운 화면에 흰 사각형으로 보이면 안 됨) |
| 해상도 | 512×512 이상 (발견 연출에서 200px로 크게 표시됨) |
| 파일당 | 40~120 KB |
| 20종 합계 | 1.5 MB 이하 |

> Cloudflare Pages 는 대역폭이 무제한이라 래스터(webp/png)를 써도 비용 문제가 없습니다.
> 남은 기준은 학교 와이파이에서의 로딩 속도뿐입니다.

## 동작 방식

- 파일이 **있으면** 그 이미지를 쓴다
- 파일이 **없으면** 코드에 내장된 임시 그림을 쓴다 (골격용, 조잡함)
- 20개 중 일부만 넣어도 된다

## 확인

```bash
npm run check:assets
```

파일명 · 투명배경 · 해상도 · 용량을 자동 점검합니다.
**파일명이 하나만 틀려도 그 유령만 조용히 임시 그림으로 나오므로 반드시 돌릴 것.**
