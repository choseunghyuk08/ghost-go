## 규격

- `viewBox="0 0 100 100"`
- 배경 투명 (흰 사각형 깔면 안 됨)
- 파일당 8 KB 이하
- 어두운 배경 `#0B0614` 위에서 잘 보일 것
- 34px 로 줄여도 형태가 구분될 것

## 동작 방식

- 파일이 **있으면** 그 이미지를 쓴다
- 파일이 **없으면** 코드에 내장된 임시 그림을 쓴다
- 20개 중 일부만 넣어도 된다 (없는 것만 임시 그림)

## 확인

```bash
npm run check:assets
```

파일명·용량·viewBox·투명배경을 자동 점검한다.
